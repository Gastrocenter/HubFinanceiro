# 05 — Cadastros e de-para

**Tipo:** AFK · **Depende de:** 04

## Escopo
- Modelo canônico: `Empresa`, `Unidade`, `Médico`, `Convênio`.
- Tela para ver e corrigir o de-para ProDoctor → Hub (o cliente opera o próprio cadastro).
- Item sem de-para vira pendência.

## Critérios de aceite
- [ ] Os cadastros sincronizados aparecem na tela com o código de origem.
- [ ] Corrigir um de-para fica registrado na auditoria.
- [ ] Médico ou convênio novo no ProDoctor gera pendência até ser mapeado.
